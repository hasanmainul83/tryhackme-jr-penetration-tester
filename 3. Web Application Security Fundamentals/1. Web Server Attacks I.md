

## Walking An Application

Manually inspect the app before touching a scanner. Source, requests, JS, cookies, storage.

```text
view-source:http://TARGET
```

DevTools (F12):

```text
Inspector   → HTML/CSS
Debugger    → JavaScript
Network     → Requests/responses
Storage     → Cookies / Local / Session Storage
```

Look for exposed info, hidden endpoints, client-side logic, and how the app talks to the backend.

## Content Discovery

Find what's not linked. Hidden dirs, files, endpoints, subdomains.

Always check first:

```text
/robots.txt
/sitemap.xml
/favicon.ico
```

Gobuster dir:

```bash
gobuster dir -u TARGET -w WORDLIST [FLAGS]
```

```text
-u          → Target URL
-w          → Wordlist
-x          → File extensions
-t          → Threads
-o          → Save output
-r          → Follow redirects
-k          → Skip TLS verification
-s          → Show status codes
--delay     → Delay between requests
```

Gobuster dns:

```bash
gobuster dns -d DOMAIN -w WORDLIST [FLAGS]
```

```text
-d   → Domain
-w   → Wordlist
-i   → Show resolved IPs
-r   → Custom DNS resolver
```

Gobuster vhost:

```bash
gobuster vhost -u TARGET -w WORDLIST [FLAGS]
```

```text
--append-domain    → Append domain
--exclude-length   → Exclude responses by length
```

## Modern Web Stacks

Fingerprint stack and version.

```bash
curl -sI http://TARGET:PORT
```

```text
-sI → Silent + response headers
```

Look for:

```text
X-Powered-By: Express  → Express
Next.js indicators     → Next.js
Django indicators      → Django
Server: Apache/x.x.x   → Apache version
```

Apache path traversal:

```bash
curl --path-as-is TARGET
```

```text
--path-as-is → Keep /../ sequences intact
```

## Web Server Attacks — I

Fingerprint and find common misconfigs.

```bash
curl -sI http://TARGET:PORT
```

Check:

```text
Server
X-Powered-By
```

Python HTTP Server:

```bash
curl -s http://TARGET:8000/
```

Apache:

```bash
curl -s http://TARGET/server-status
```

```text
Server header
Directory listing
/server-status
Backup files
.htpasswd
```

Node.js / Express:

```bash
curl -sI http://TARGET:3000
```

```text
X-Powered-By: Express
Routes
Debug endpoints
Config files
```

Nginx:

```bash
curl -sI http://TARGET:8080
```

```text
server_tokens → Version disclosure
autoindex     → Directory listing
stub_status   → Status info
```

Nikto:

```bash
nikto -h http://TARGET
```
