# AD: Basic Enumeration 

## 1. Host Discovery

**fping — find live hosts**

```bash
fping -agq 10.211.11.0/24
```

- `-a` — show live hosts.
    
- `-g` — generate target list from subnet.
    
- `-q` — quiet output.
    

**Nmap — discover live hosts**

```bash
nmap -sn 10.211.11.0/24
```

Save discovered in-scope hosts to `hosts.txt`.

## 2. Port Scanning

**Common AD ports**

|Port|Service|
|---|---|
|88|Kerberos|
|135|MS-RPC|
|139|NetBIOS/SMB|
|389|LDAP|
|445|SMB|
|464|Kerberos password service|
|636|LDAPS|

**Service/version detection**

```bash
nmap -p 88,135,139,389,445,636 -sV -sC -iL hosts.txt
```

- `-sV` — detect service versions.
    
- `-sC` — run default NSE scripts.
    
- `-iL` — read targets from a file.
    

**Full TCP port scan**

```bash
nmap -sS -p- -T3 -iL hosts.txt -oN full_port_scan.txt
```

**DC clue:** Kerberos, LDAP, and SMB open together often indicate a Domain Controller. Confirm using scan results and domain information.

## 3. SMB Enumeration

**List shares anonymously**

```bash
smbclient -L //DC_IP -N
```

- `-L` — list shares.
    
- `-N` — do not prompt for a password.
    

**Check share permissions**

```bash
smbmap -H DC_IP
```

**Nmap share enumeration**

```bash
nmap -p445 --script smb-enum-shares DC_IP
```

**Connect to an accessible share**

```bash
smbclient //DC_IP/SHARE_NAME -N
```

Inside the SMB prompt:

```text
ls
cd DIRECTORY
get FILE_NAME
put FILE_NAME
exit
```

- `get` — download a file.
    
- `put` — upload a file; requires write permission.
    

**Look for:** Backups, scripts, configuration files, documents, usernames, and exposed credentials.

**With credentials**

```bash
smbclient //DC_IP/SHARE_NAME -U 'DOMAIN\USER'
```

## 4. LDAP Enumeration

**Test anonymous LDAP access**

```bash
ldapsearch -x -H ldap://DC_IP -s base
```

- `-x` — simple authentication; no credentials are supplied here.
    
- `-H` — LDAP server URL.
    
- `-s base` — query only the base object.
    

**Enumerate person objects**

```bash
ldapsearch -x -H ldap://DC_IP \
-b "dc=tryhackme,dc=loc" "(objectClass=person)"
```

Replace the base DN with the target domain's naming context.

**Why it matters:** Anonymous LDAP access may expose domain information or user objects if the server permits it.

## 5. Automated Enumeration

**enum4linux-ng**

```bash
enum4linux-ng -A DC_IP -oA results
```

- `-A` — broad enumeration of users, groups, shares, password policy, and system information.
    
- `-oA` — save results in YAML and JSON formats.
    

Review the results for valid users, accessible shares, domain details, and policy information.

## 6. RPC Null Sessions

**Connect without credentials**

```bash
rpcclient -U "" DC_IP -N
```

Inside `rpcclient`:

```text
enumdomusers
enumdomgroups
getdompwinfo
queryuser RID
```

- `enumdomusers` — enumerate domain users.
    
- `enumdomgroups` — enumerate domain groups.
    
- `getdompwinfo` — retrieve password-policy information if permitted.
    
- `queryuser RID` — query a user by relative identifier.
    

**RID basics**

- `500` — built-in Administrator account.
    
- `501` — Guest account.
    
- `512` — Domain Admins group.
    
- `513` — Domain Users group.
    
- `514` — Domain Guests group.
    
- Normal user RIDs commonly start at `1000` or above.
    

**RID cycling — query a range**

```bash
for i in $(seq 500 2000); do
  echo "queryuser $i" |
  rpcclient -U "" -N DC_IP 2>/dev/null |
  grep -i "User Name"
done
```

RID cycling can reveal account names when normal user enumeration is restricted, provided anonymous RPC queries are allowed.

## 7. Password Policy Enumeration

**Using rpcclient**

```text
getdompwinfo
```

**Using NetExec**

```bash
nxc smb DC_IP --pass-pol
```

Check:

- Minimum password length.
    
- Password complexity.
    
- Account lockout threshold.
    
- Lockout duration and reset timer.
    

Use this information to assess password-spraying risk before testing credentials. See the **AD Breaching** note for the Kerbrute and password-spraying workflow.

## Core Workflow

**Discover hosts → Identify the DC → Scan AD ports → Enumerate SMB shares → Check anonymous LDAP/RPC → Collect users and password policy → Review accessible files for useful information.**
