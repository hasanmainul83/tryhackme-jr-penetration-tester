
| Acronym    | Full form                                          | Meaning                                                                                           |
| ---------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| AD         | Active Directory                                   | Microsoft's directory service for managing users, computers, groups, and domain resources.        |
| DC         | Domain Controller                                  | A server that handles Active Directory authentication and domain management.                      |
| DNS        | Domain Name System                                 | Resolves hostnames into IP addresses.                                                             |
| FQDN       | Fully Qualified Domain Name                        | The complete domain name of a host, such as `DC01.ctf.local`.                                     |
| NetBIOS    | Network Basic Input/Output System                  | Used for identifying computers and enabling communication over a network.                         |
| LLMNR      | Link-Local Multicast Name Resolution               | A protocol used to resolve hostnames on a local network.                                          |
| NBT-NS     | NetBIOS Name Service                               | A service used to resolve NetBIOS names into IP addresses.                                        |
| mDNS       | Multicast Domain Name System                       | Provides DNS-style name resolution on a local network.                                            |
| NTLM       | NT LAN Manager                                     | Microsoft's authentication protocol.                                                              |
| NetNTLMv2  | Network NT LAN Manager Version 2                   | A network authentication challenge-response mechanism based on NTLMv2.                            |
| SSP        | Security Support Provider                          | Provides authentication security protocols within the Windows security architecture.              |
| SMB        | Server Message Block                               | A network protocol used for sharing files and resources.                                          |
| SMBv1      | Server Message Block Version 1                     | The first version of the SMB protocol.                                                            |
| CIFS       | Common Internet File System                        | An older dialect of the SMB file-sharing protocol.                                                |
| IPC        | Inter-Process Communication                        | Communication between different processes.                                                        |
| LDAP       | Lightweight Directory Access Protocol              | A protocol used to access and manage directory information in Active Directory.                   |
| LDAPS      | Lightweight Directory Access Protocol over SSL/TLS | Provides encrypted LDAP communication.                                                            |
| RPC        | Remote Procedure Call                              | A mechanism that allows procedures to be executed on remote machines.                             |
| MSRPC      | Microsoft Remote Procedure Call                    | Microsoft's implementation of Remote Procedure Call for Windows.                                  |
| RDP        | Remote Desktop Protocol                            | A protocol used to remotely access Windows machines.                                              |
| IP         | Internet Protocol                                  | Provides addressing and routing of packets across networks.                                       |
| TCP        | Transmission Control Protocol                      | A reliable, connection-oriented communication protocol.                                           |
| UDP        | User Datagram Protocol                             | A connectionless communication protocol.                                                          |
| ICMP       | Internet Control Message Protocol                  | Used for network diagnostics and error reporting, including `ping`.                               |
| VPN        | Virtual Private Network                            | Establishes a secure network tunnel.                                                              |
| MAC        | Media Access Control                               | Identifies a network interface through its hardware address.                                      |
| NIC        | Network Interface Card                             | A hardware or virtual interface that connects a machine to a network.                             |
| MTU        | Maximum Transmission Unit                          | The maximum packet size that can be transmitted over a network interface.                         |
| KDC        | Key Distribution Center                            | Issues and manages Kerberos tickets.                                                              |
| TGT        | Ticket-Granting Ticket                             | A Kerberos ticket used to request service tickets.                                                |
| TGS        | Ticket-Granting Service                            | A Kerberos service that issues service tickets.                                                   |
| SPN        | Service Principal Name                             | Uniquely identifies a service within Kerberos authentication.                                     |
| S4U        | Service for User                                   | A set of Kerberos extensions that allows services to request tickets on behalf of users.          |
| S4U2Self   | Service for User to Self                           | Allows a service to request a service ticket to itself on behalf of another user.                 |
| S4U2Proxy  | Service for User to Proxy                          | Allows a service to request a ticket for an authorised backend service on behalf of another user. |
| CCache     | Credential Cache                                   | A format used to store Kerberos tickets locally.                                                  |
| KRB5       | Kerberos Version 5                                 | Version 5 of the Kerberos authentication protocol.                                                |
| KRB5CCNAME | Kerberos 5 Credential Cache Name                   | An environment variable that specifies the location of the Kerberos credential cache.             |
| UNC        | Universal Naming Convention                        | A format for specifying network resource paths in Windows, such as `\\SERVER\SHARE`.              |
| UID        | User Identifier                                    | A numerical identifier assigned to a Linux user.                                                  |
| PID        | Process Identifier                                 | A unique numerical identifier assigned to a running process.                                      |
| PPID       | Parent Process Identifier                          | The identifier of the parent process of a running process.                                        |
| SSL        | Secure Sockets Layer                               | An older cryptographic protocol designed to secure network communications.                        |
| TLS        | Transport Layer Security                           | A cryptographic protocol used to secure network communications.                                   |
