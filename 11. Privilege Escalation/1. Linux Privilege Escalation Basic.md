# Host Configuration & PrivEsc 

**Core Rule:** A fully patched system can still be vulnerable due to misconfigurations, weak permissions, or exposed credentials.

## 1. Tools

- **LinPEAS** → Linux privilege-escalation enumeration.
    
- **WinPEAS** → Windows enumeration.
    
- **PowerUp.ps1** → Windows privilege-escalation checks (`Invoke-AllChecks`).
    
- **GTFOBins** → Check ways to abuse permitted Linux binaries.
    

## 2. Linux Checks

```bash
# Current user and groups
id
sudo -l

# SUID binaries
find / -perm -4000 -type f 2>/dev/null

# Linux capabilities
getcap -r / 2>/dev/null

# Cron jobs
cat /etc/crontab
ls -la /etc/cron.*

# Writable files
find / -writable -type f 2>/dev/null | grep -vE '/proc|/sys'
```

**Look for:** `NOPASSWD` sudo rules, exploitable SUID binaries, dangerous capabilities, root cron jobs with writable scripts, and sensitive files.

## 3. Windows Checks

```cmd
:: User and privileges
whoami /all
whoami /priv

:: Saved credentials
cmdkey /list

:: Services
sc query
sc qc SERVICE_NAME

:: Scheduled tasks
schtasks /query /fo LIST /v

:: File permissions
icacls "C:\Path\To\File"
```

**Look for:**

- `SeImpersonatePrivilege` and `SeAssignPrimaryTokenPrivilege`
    
- Unquoted service paths and writable service files
    
- Scheduled tasks running as SYSTEM with writable scripts
    
- Saved credentials and weak file permissions
    

## 4. Enumeration Workflow

1. **Identify:** `id` (Linux), `whoami /all` (Windows).
    
2. **Enumerate:** Run PEAS, then verify findings manually.
    
3. **Investigate:** Sudo rules, SUID, capabilities, services, scheduled tasks, credentials.
    
4. **Escalate:** Validate the safest applicable privilege-escalation path.
    
5. **Pivot:** Check discovered credentials for access to other in-scope systems.
    

**Remember:** Docker, LXD, or `disk` group membership can provide privilege-escalation paths depending on configuration.




```
cat /etc/os-release   # OS version
cat /proc/version     # Kernel build information
ps axjf               # Process tree
dpkg -l               # Installed packages
ls -la                # Show hidden files
```
