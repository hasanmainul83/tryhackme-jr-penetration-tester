Passive reconnaissance is all about gathering intelligence from **publicly available sources** without directly interacting with the target. 

Now, let’s see which tools we can use for reconnaissance.
Tools:
- WHOIS
- nslookup
- dig
- DNSDumpster
- Shodan.io


1. WHOIS is a protocol used to retrieve domain registration information such as the registrar, registration dates, nameservers, and available registrant details.

Command:

```
whois example.com
```

Modern alternative — **RDAP (Registration Data Access Protocol):**

```
curl -s https://rdap.verisign.com/com/v1/domain/example.com | jq .
```

Flags / options:

- `-s` — **Silent mode**; suppresses progress and error messages from `curl`.
- `jq` — **JSON processor** used to format and parse the RDAP response for easier reading.



2. `dig` (Domain Information Groper) is a DNS query tool used to retrieve records such as **A, AAAA, MX, CNAME, SOA, and TXT** from DNS.

- **A** — Address
- **AAAA** — IPv6 Address
- **MX** — Mail Exchange
- **CNAME** — Canonical Name
- **SOA** — Start of Authority
- **TXT** — Text Record

Command syntax:

```
dig [@SERVER] DOMAIN_NAME [TYPE]
```

Example:

```
dig @1.1.1.1 example.com MX
```




3.  DNSDumpster is a passive reconnaissance tool used to discover **subdomains, DNS records, IP addresses, and related hosts** for a domain.

     How to use:
       Open `https://dnsdumpster.com/` and enter the target domain.



4. Shodan is a search engine for **Internet-connected devices and exposed services**, revealing information such as **open ports, software, and service banners**.

Command syntax:

```
shodan search QUERY
```

Example:

```
shodan search hostname:example.com
```
