We’ve covered passive reconnaissance. Now let’s interact directly with the target.

Active reconnaissance is the process of directly interacting with a target system or network to gather information about it.
### Active Reconnaissance Tools
- Web Browser
- Traceroute
- Ping
- Telnet
- Netcat (nc)

1. A web browser lets us directly interact with web applications and inspect information that may not be visible on the page itself.

Use cases:
- Inspect HTTP requests and response headers
- Discover JavaScript files, API endpoints, and hidden paths
- Inspect cookies, Local Storage, and Session Storage
- Check TLS certificates and exposed domain names
- Identify technologies used by the application


2. Traceroute shows the path packets take from your system to the target, revealing the intermediate routers (hops) between your system and the destination.

Command syntax:

```
traceroute MACHINE_IP
```

Example:

```
traceroute 10.10.10.10
```

Useful options:

```
traceroute -T MACHINE_IP    # TCP-based tracing
traceroute -I MACHINE_IP    # ICMP-based tracing
traceroute -6 MACHINE_IPV6  # IPv6 tracing
```
Note: 👇🏻
`*` in the output means a hop did not return a response.


3. Ping checks whether a target host is reachable by sending ICMP Echo Requests and waiting for ICMP Echo Replies.

Command syntax:

```
ping -c COUNT TARGET
```

Example:

```
ping -c 5 10.10.10.10
```

Useful flags:

```
-c 5    # Send 5 packets
-4      # Use IPv4
-6      # Use IPv6
```



4. Telnet is a remote communication protocol that uses TCP, but for active reconnaissance it is mainly useful for connecting to TCP ports and performing banner grabbing.
 
 Command syntax:

```
telnet TARGET PORT
```

Example:

```
telnet 10.10.10.10 80
```

For a web server, you can then send a basic HTTP request:

```
GET / HTTP/1.1
Host: example.com
```

The response may reveal a banner such as `Server: nginx/1.6.2`.  


5. Netcat (`nc`) is a networking utility that supports TCP and UDP and is commonly used in active reconnaissance for banner grabbing and port probing.

Command syntax:

```
nc TARGET PORT
```

Example:

```
nc 10.10.10.10 80
```

Useful flags:

```
-l    # Listen mode
-p    # Specify port
-n    # Disable DNS resolution
-v    # Verbose output
-vv   # Very verbose output
-k    # Keep listening after disconnect
```
