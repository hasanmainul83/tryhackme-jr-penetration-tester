
The architecture or workflow lacks essential security controls. The flaw is in the design, not necessarily the code.

## Common Examples

- Weak password recovery
    
- Bypassing approval workflows
    
- Missing business rules, limits, or rate checks
    
- Trusting client-side values (price, role, quantity)
    
- Broken access assumptions between users
    
- Unsafe AI/automation workflows
    
- Missing abuse-case analysis
    

## Test Flow

```
Normal flow
→ Skip a step
→ Change the sequence
→ Repeat an action
→ Manipulate state
```

Example: Skip transaction approval and try to complete the action anyway.

## Prevention

- Threat modeling and abuse-case analysis
    
- Separation of duties
    
- Fail-safe defaults and least privilege
    
- Defense in depth
    
- Enforce security checks server-side
    

## Mindset

Can I abuse the workflow even when individual functions work correctly?
