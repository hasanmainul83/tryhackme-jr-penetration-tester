
Something was left enabled, exposed, or incorrectly configured. The problem is in the setup, not necessarily the code.

## Look For

- Default credentials
    
- Exposed admin panels (`/admin`, `/manager`, `/console`)
    
- Directory listing
    
- Debug mode (`DEBUG=True`, `APP_DEBUG=true`)
    
- Verbose errors (stack traces, SQL errors)
    
- Missing security headers (CSP, HSTS, X-Frame-Options)
    
- Open cloud storage (S3, Azure Blob, GCS)
    
- CORS misconfiguration (untrusted origin allowed to read sensitive responses)
    
- Overly permissive cloud/network permissions (`*`, `0.0.0.0/0`)
    
- Kubernetes misconfiguration (privileged pods, `hostPath` mounts, exposed/default tokens)
    
- Unused ports, services, or sample applications

## Quick Checks

```
curl -i https://TARGET/
nmap -sV TARGET
curl -s https://TARGET/ | grep -i "index of"
curl -i -H "Origin: https://evil.com" https://TARGET/api/user
aws s3 ls s3://BUCKET --no-sign-request
```
