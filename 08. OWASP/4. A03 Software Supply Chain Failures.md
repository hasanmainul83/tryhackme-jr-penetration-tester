
Compromised dependencies, packages, maintainers, or CI/CD pipelines can compromise an application. New in OWASP Top 10 2025.

## Attack Techniques

- **Dependency Confusion** → Malicious public package replaces an internal dependency.
    
- **Typosquatting** → Fake package uses a similar name.
    
- **Maintainer Takeover** → Compromised account publishes malicious updates.
    
- **CI/CD Poisoning** → Abuse workflows, permissions, or caches.
    
- **Preinstall Hooks** → Malicious scripts execute during installation.
    
- **Shai-Hulud** → npm worm that steals credentials and spreads.
    
- **Config Poisoning** → Malicious `.npmrc` or Git configuration.
    

## Look For

- Outdated or malicious dependencies
    
- Unpinned packages and actions
    
- Exposed build secrets
    
- Overly permissive CI/CD permissions
    
- Untrusted updates
    

## Quick Checks

```
npm audit
pip-audit

```

## Tools

- **Syft** — Generate SBOMs.
    
- **Grype** — Scan for known vulnerabilities.
    
- **Socket.dev** — Detect malicious packages.
    
- **Snyk** — Scan dependencies.
    
- **Checkov** — Scan infrastructure-as-code.
    
- **OWASP Dependency-Check** — Identify vulnerable dependencies.
    

## Mindset

Can a package, maintainer, registry, or CI/CD pipeline the application trusts be compromised?
