
Sensitive data isn't properly protected due to weak encryption, poor key management, or exposed secrets.

## Look For

- Weak algorithms (MD5, SHA-1, DES, RC4)
    
- Weak password storage (plaintext, MD5, SHA-1)
    
- Hard-coded keys or secrets
    
- Predictable session IDs or reset tokens
    
- HTTP instead of HTTPS
    
- Weak TLS or insecure modes (ECB, IV/nonce reuse)
    
- Poor key management
    
- Sensitive data exposed in logs
    

## Quick Checks

```
# TLS and certificates
openssl s_client -connect TARGET:443

# Identify hash type
hashid HASH

# Scan Git history for secrets
trufflehog git https://github.com/ORG/REPO

# Check for exposed secrets
curl -s https://TARGET/ | grep -iE "key|secret|token|password"
```

## Mindset

Can sensitive data, keys, or authentication tokens be recovered or forged?
