- **Workflow:** `hashid HASH` → Identify mode → Crack.
    
- **Hashcat (GPU - Fast):**
    
    - `hashcat -m 1000 hashes.txt words.txt -r rules/best64.rule` (1000 = NTLM)
        
    - _Tip:_ Run `hashcat --example-hashes` if stuck on a mode. Don't guess `-m`.
        
- **John the Ripper (CPU - Versatile):**
    
    - `john --wordlist=words.txt --rules=Jumbo hashes.txt`
        
- **Attack Modes:**
    
    - Dictionary (straight)
        
    - Rule-based (best for real-world passwords)
        
    - Mask (brute-force specific patterns: `?u?l?l?l?d?d`)
        

**Golden Rule:** If you have a hash, always try `hashid` and `hashcat --example-hashes` before wasting CPU/GPU cycles.
